# Activity 1 – Development Environment Setup

1. I installed Visual Studio Code to write and execute C programs.
2. I installed the Microsoft C/C++ extension in VS Code.
3. I installed MinGW-w64 to configure the GCC compiler.
4. Initially, I faced an issue where GCC was not recognized in the terminal.
5. I resolved this by adding the MinGW `bin` folder to the system PATH environment variable.
6. I verified the installation using the `gcc --version` command.
7. Finally, I created and executed `hello.c` successfully and received the output "Hello, World!".
